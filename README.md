# Is it worth breaking into the Data World?

## Overview
Analyzed survey responses from 630 data professionals in Power BI to evaluate salaries, work-life balance, career transitions, and entry barriers across roles and regions.

## Key Insights
* **Salary Gap:** Data Scientists average **$94K/yr**, nearly 3x Database Developers ($33K).
* **Satisfaction:** Work/life balance satisfaction (**5.74/10**) outperforms salary satisfaction (**4.27/10**).
* **Career Switchers:** **59%** (372/630) transitioned into data from other fields.
* **Geographics:** US pays highest ($78K average); India pays lowest ($30K average).

## Conclusions
* **Accessible Entry:** **68%** found breaking into data neutral or easy, showing technical backgrounds aren't required.
* **Balanced Trade-off:** Data roles are ideal for work-life balance, but income varies widely by role and location.
